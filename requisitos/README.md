# Requisitos funcionais

Requisitos funcionais do GeFi.

| ID | Requisito funcional |
|---|---|
| RF01 | Autenticar com conta Google, restrita a e-mails convidados |
| RF02 | Gerenciar usuários e restringir funções por perfil (administrador) |
| RF03 | Enviar, listar e excluir documentos PDF, identificados por SHA-256 (administrador) |
| RF04 | Indexar os documentos pela estrutura normativa (pai e filho), registrando página e posição |
| RF05 | Responder a perguntas em linguagem natural com base nos documentos, com recuperação hierárquica |
| RF06 | Adaptar a resposta ao tipo de pergunta, com recusa padronizada e aviso de falha técnica ou corte |
| RF07 | Apresentar a fundamentação na própria resposta, com citação estrutural ligada à fonte |
| RF08 | Exibir o documento consultado na página citada, com o trecho da fundamentação destacado, e permitir copiar o trecho e baixar o original |
| RF09 | Manter o histórico de conversas: criar, listar, reabrir com fontes, fixar, renomear e excluir |
